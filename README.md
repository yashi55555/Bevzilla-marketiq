
# Bevzilla MarketIQ

## AI-Powered Marketing Operations & Intelligence Platform

Bevzilla MarketIQ is an academic prototype that integrates Retrieval-Augmented Generation (RAG), marketing analytics, streaming data analytics and real-time business intelligence into a unified marketing operations platform.

## Core Technologies

- Docling
- LlamaIndex
- Qdrant
- Ollama
- PostgreSQL
- Apache Kafka
- Grafana
- Power BI
- Python
- Streamlit
- Docker

## Core Capabilities

- Multi-department document intelligence
- RAG-based enterprise knowledge retrieval
- Structured marketing analytics
- Real-time streaming analytics
- Live marketing operations monitoring
- Customer and competitor intelligence
- AI-powered marketing insights
- Interactive web dashboard

## Architecture

Public/Synthetic Data
→ Data Processing
→ PostgreSQL / Qdrant / Kafka
→ Analytics & RAG
→ AI Intelligence
→ Grafana / Power BI / Streamlit

## Use Case

The prototype is designed around a Bevzilla-inspired consumer-brand marketing operations use case using publicly available and synthetic data.

Currently under development.
